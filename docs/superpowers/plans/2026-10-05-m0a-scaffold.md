# M0a Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working pnpm monorepo with a NestJS API (config, Postgres via Prisma, health endpoint), a React POS web app shell, a React QR app shell, a shared package, a production Docker build, and CI — all green and runnable locally.

**Architecture:** pnpm workspace with `apps/api` (NestJS modular monolith, Prisma, global `/api` prefix), `apps/web` (Vite + React SPA with `/pos`, `/captain`, `/kds`, `/admin` areas), `apps/qr` (Vite + React served under `/qr/`), and `packages/shared` (Zod schemas and money utilities, built to ESM + CJS with tsup). Postgres runs in Docker for development and tests. Production is one Docker Compose stack: postgres, api, and nginx serving both SPAs and proxying `/api`.

**Tech Stack:** Node 24, pnpm 10.17.1, TypeScript 5, NestJS 11, Prisma 6, PostgreSQL 16, React 19, Vite 7, React Router 7, TanStack Query 5, Tailwind CSS 4, Zod 4, Jest 29 (api), Vitest 3 (shared, web, qr), Docker Compose, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-03-restaurant-pos-prd-design.md` (sections 3, 4.1, 7, 8, 9 — milestone M0, scaffold half)

**Out of scope (next plan, M0b):** auth (password + PIN + JWT), roles and permission guards, outlet settings UI, device pairing, HTTPS/Let's Encrypt, nightly backups, VPS deployment runbook, Socket.IO gateway.

## Global Constraints

- Node `>=24`; pnpm pinned via `"packageManager": "pnpm@10.17.1"`; TypeScript major 5; PostgreSQL 16.
- Workspace package names use the `@rpos/` scope: `@rpos/shared`, `@rpos/api`, `@rpos/web`, `@rpos/qr`.
- Frontend is React + Vite. Do not introduce Next.js.
- ORM is Prisma. Tables and columns are snake_case via `@@map` / `@map`; primary keys are UUIDs; every table has `created_at` and `updated_at` as `timestamptz`.
- Money is stored as integer paise and formatted with the `en-IN` locale (Indian digit grouping, `₹`).
- API routes live under the global prefix `/api`.
- English-only UI copy.
- Line endings are LF everywhere (enforced by `.gitattributes`); the developer machine is Windows.
- Dev Postgres listens on host port `5433` (container `5432`) to avoid clashing with any local install.
- Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **API starts while Postgres is down or still booting** — the API must stay up and `GET /api/health` must answer `503 {"status":"error","db":"down"}` within about 2 seconds, never hang or crash. Pinned in Task 2 (service timeout + reject tests, e2e override test).
2. **Missing or malformed environment variables** — startup must fail with a message naming the bad variable (e.g. `DATABASE_URL`), not a stack trace from deep inside Prisma. Pinned in Task 2 (`env.spec.ts`).
3. **Requests from an origin that is not configured** — CORS must allow only `CORS_ORIGINS`; a random site must not get `Access-Control-Allow-Origin`. Pinned in Task 2 (CORS e2e test).
4. **Server unreachable or returning garbage** — the web app must show "Server offline" rather than a blank page or crash. Pinned in Task 3 (`ServerStatus.test.tsx`: network error and malformed body cases).
5. **Refreshing a deep link in production** (`/pos`, `/kds`, `/qr/?t=abc`) — nginx must return the SPA's `index.html`, not 404. Pinned in Task 5 (curl verification steps).

`packages/shared/src/money.ts`:
```ts
/** Money is stored as integer paise (1 rupee = 100 paise). */
export type Paise = number;

const inr = new Intl.NumberFormat('en-IN', {
  style: 'currency',
  currency: 'INR',
  minimumFractionDigits: 2,
  maximumFractionDigits: 2,
});

export function rupeesToPaise(rupees: number): Paise {
  if (!Number.isFinite(rupees)) {
    throw new RangeError(`Invalid rupee amount: ${rupees}`);
  }
  // Round half away from zero so -12.345 and 12.345 mirror each other; `+ 0` turns -0 into 0.
  return Math.sign(rupees) * Math.round(Math.abs(rupees) * 100) + 0;
}

export function formatPaise(paise: Paise): string {
  if (!Number.isSafeInteger(paise)) {
    throw new RangeError(`Paise must be a safe integer: ${paise}`);
  }
  return inr.format(paise / 100);
}
```

  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  PORT: z.coerce.number().int().min(1).max(65535).default(3000),
  DATABASE_URL: z
    .string()
    .regex(/^postgres(ql)?:\/\//, 'must be a postgres:// or postgresql:// URL'),
  CORS_ORIGINS: z
    .string()
    .default('http://localhost:5173,http://localhost:5174')
    .transform((value) =>
      value
        .split(',')
        .map((origin) => origin.trim())
        .filter(Boolean),
    ),
});

export type Env = z.infer<typeof envSchema>;

export function parseEnv(raw: Record<string, string | undefined>): Env {
  const result = envSchema.safeParse(raw);
  if (!result.success) {
    const issues = result.error.issues
      .map((issue) => `${issue.path.join('.')}: ${issue.message}`)
      .join('; ');
    throw new Error(`Invalid environment configuration: ${issues}`);
  }
  return result.data;
}

import { Injectable } from '@nestjs/common';
import type { HealthResponse } from '@rpos/shared';
import { PrismaService } from '../prisma/prisma.service';

const DEFAULT_TIMEOUT_MS = 2000;

function withTimeout<T>(promise: PromiseLike<T>, ms: number): Promise<T> {
  let timer: NodeJS.Timeout | undefined;
  const timeout = new Promise<never>((_, reject) => {
    timer = setTimeout(() => reject(new Error(`Timed out after ${ms}ms`)), ms);
  });
  return Promise.race([Promise.resolve(promise), timeout]).finally(() => clearTimeout(timer));
}

@Injectable()
export class HealthService {
  constructor(private readonly prisma: PrismaService) {}

  async check(timeoutMs = DEFAULT_TIMEOUT_MS): Promise<HealthResponse> {
    const dbUp = await withTimeout(this.prisma.$queryRaw`SELECT 1`, timeoutMs).then(
      () => true,
      () => false,
    );
    return dbUp ? { status: 'ok', db: 'up' } : { status: 'error', db: 'down' };
  }
}

function readTableToken(search: string): string | null {
  const token = new URLSearchParams(search).get('t')?.trim();
  return token ? token : null;
}

  return (

        <>
